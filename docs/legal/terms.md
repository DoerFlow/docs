# DoerFlow 用户协议

**版本**：2026-09-05 · 封闭 Beta / 早期主网

使用 DoerFlow（含 web、wallet、worker、API 与智能合约）即表示你已阅读并同意本协议。平台登录或首次连接钱包时须勾选确认。

勾选同意本协议，即同时接受本协议，以及作为其组成部分的 [LuminaryWorks 平台服务条款](https://luminaryworks.dev/legal/terms) 与 [隐私政策](https://luminaryworks.dev/legal/privacy)。账号、身份与集团层面的免责以平台服务条款为准；钱包、托管、链上资产与前期不予赔付以本协议为准。

## 1. 服务性质

DoerFlow 是初创阶段的任务与结算协议。产品会先上线、再打磨，功能与安全状况可能不完整。

## 2. 前期不予赔付

在平台将 `COMMERCIAL_COMPENSATION` 改为已资助的赏金计划并公开赏金页之前：

- 不对智能合约漏洞、链下账本/索引故障、黑客攻击、停机或资金损失作任何赔偿或保险。
- 不设 Bug Bounty 赏金池；向 `security@doerflow.dev` 报告漏洞 **不构成** 获赔承诺。
- 不提供官方回购、理赔或资金保障。

Merkle `forceWithdraw` 与 Vault `withdraw` 是你在链上的 **自助退出**，不是平台赔付。

## 3. 非托管

DoerFlow 不保管你的助记词或主私钥。链上签名由你的钱包完成。丢失密钥、签错交易或被钓鱼导致的损失由你自行承担。

## 4. 封闭测试

主网封闭 Beta 可能限制邀请地址与单笔/总锁仓上限，并可能暂停新充值。测试网资产无主网价值。

## 5. 适用法律

DoerFlow 没有 Trial。钱包与链上资产不是托管资金，丢失密钥或签错交易的损失由你承担。托管登录运行在 OVH，适用法国法。强制性消费者规则和 GDPR 不因此减损。自行创建账户须年满 15 周岁。联系 admin@luminaryworks.dev。登记信息以 https://luminaryworks.dev/legal 页眉为准。

## 6. 协议变更

我们可能更新本协议。继续使用即视为接受更新后的文本。最新全文以本页为准。
